# ADR 0002: Static, local-first Signal Wall boundary

- Status: Accepted
- Date: 2026-07-16

## Decision
Signal Wall remains a static, local-only prototype. It has no accounts, persistence, analytics, media playback, embeds, APIs, workers, or social rooms. The host must enforce restrictive headers. External media is prohibited until a reviewed adapter, rights record, privacy review, and ADR exist.

Hybrid history, disabled tuning while off, persistent mute, roving tabindex, user-selectable effects, and unavailable unknown fragments are accepted.

## Consequences
This is a deterministic microworld, not evidence that YouTube, AT Protocol, legal-media ingestion, or watch rooms are ready.
